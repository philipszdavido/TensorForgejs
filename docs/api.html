Core Memory Structures

Vector

1D optimized numeric array backed by low-level flat typed buffers.

  • new Vector(size) - Initialize clear buffer.
  • set(index, value) / get(index) - Explicit buffer manipulation.
  • sum() / avg() - Analytical scalar reducers.
  • static from(array) - Instantiates vector out of raw JavaScript arrays.

Matrix

2D structured layout utilizing explicit row-major performance mapping layouts.

  • new Matrix(rows, columns) - Allocates 2D structure.
  • matrixMulVector(matrix, vector) - High performance standard dot engine multiplication.
  • outerProduct(vectorA, vectorB) - Builds a full 2D output layout.
