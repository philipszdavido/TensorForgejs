Supported Model Classes

TensorForge comes equipped with classic algorithms built directly on structural primitive arrays.

  • Linear Regression - Computes continuous targets analytically.
  • Logistic Regression - Binary classification using dynamic sigmoids.
  • Naive Bayes - Maximum a-posteriori probabilistic mapping engines.
  • Support Vector Machines (SVM) - Boundary tracking using linear, polynomial, or sigmoid kernels.
